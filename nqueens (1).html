The Problem

Place N chess queens on an N×N board so no two queens attack each other — horizontally, vertically, or diagonally.

Algorithm

One queen per row. Try each column, check safety, recurse. On conflict, remove the queen and try the next column (backtrack).

Reading the Log

→ Trying — evaluating a cell.
✓ Placed — safe, queen added.
✗ Rejected — conflict found.
↩ Backtrack — queen removed.
★ Solution — all N placed!
